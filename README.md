# BCG X Customer Churn Prediction

## Overview

This project was completed as part of the BCG X Data Science Virtual Experience Program on Forage.

The objective was to analyze customer behavior, engineer meaningful features, and develop a machine learning model capable of predicting customer churn.

---

## Project Workflow

### 1. Business Understanding
- Identified potential causes of customer churn
- Defined business objectives and success metrics

### 2. Exploratory Data Analysis (EDA)
- Data quality assessment
- Missing value analysis
- Statistical summaries
- Distribution visualization

### 3. Feature Engineering
- Customer tenure features
- Consumption-based features
- Pricing variation features
- Aggregated historical pricing metrics

### 4. Predictive Modeling
- Random Forest Classifier
- Train/Test Split
- Churn Prediction

### 5. Model Evaluation
- Accuracy Score
- Precision
- Recall
- F1 Score
- ROC-AUC Analysis
- Confusion Matrix

---

## Key Findings

- Customer margins strongly influence churn.
- Consumption behavior is an important predictor.
- Customer tenure impacts retention likelihood.
- Pricing factors contribute to churn but are not the sole driver.
